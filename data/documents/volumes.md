# Docker Volumes

Docker volumes are the preferred mechanism for persisting data generated by and used by Docker containers.

## Creating a volume

```bash
docker volume create my-vol
```

List volumes:

```bash
docker volume ls
```

Inspect a volume:

```bash
docker volume inspect my-vol
```

## Mounting a volume

When you start a container, you can mount a volume with the `-v` or `--mount` flag.

Example with `-v`:

```bash
docker run -d \
  --name devtest \
  -v my-vol:/app \
  nginx:latest
```

Example with `--mount` (recommended):

```bash
docker run -d \
  --name devtest \
  --mount source=my-vol,target=/app \
  nginx:latest
```

## Named volumes vs bind mounts

- **Named volumes** are managed by Docker and stored under `/var/lib/docker/volumes/` on Linux.
- **Bind mounts** map a host path directly into the container (`-v /host/path:/container/path`).

Volumes survive container removal. Bind mounts depend on the host filesystem.

## Removing a volume

```bash
docker volume rm my-vol
```

A volume can only be removed if no container is using it.
